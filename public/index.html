What a fingerprint has to do with any of this

Every file has its own fingerprint, a short string generated from its exact contents, the same way a wax seal on a letter shows whether it was opened. Change even a single pixel or character, and the fingerprint changes completely. Compare two fingerprints, and you know immediately whether the files behind them are truly identical.

Feature highlights

More than a simple match or no match.

A single pixel or character change should not look the same as a complete rewrite. Here is how we tell the difference.

Similarity scoring

See a percentage score instead of only pass or fail, so a small edit does not look the same as a major change.

Line by line diff

For documents and text files, see exactly which lines were added, removed, or changed, laid out like a code review.

Visual diff overlay

For images, see exactly which regions changed, highlighted directly on the picture itself.

Metadata comparison, plus timelines for video and audio

Spot changes to capture time, editing software, or location data even when the picture looks the same, and for video and audio, see roughly where in the file differences were found.
